# 大模型整体认知
1. 什么是大语言模型？

    大语言模型是一个通过海量文本数据训练出来的神经网络，他学会了根据上下文预测接下来可能出现的内容。
    
    例如输入：
    ```text
    中国的首都是
    ```
    大模型根据训练中见过的大量语言模式，判断后面可能是：

    ```
    北京
    ```
    
2. 训练和推理的区别
    
- 训练：训练是模型“学习”的过程，通过阅读海量文本，不断练习一个任务：
    
     ```
     给定前面的token，预测下一个token
     ```

     如果预测错了，根据误差调整参数。
     这个过程需要大量GPU算力、数据和时间。
- 推理：推理是模型“使用”的过程

    当向模型提问时，模型已经训练好了。它会根据当前输入生成回答。
    
    |  | 训练 | 推理 |
    |---|---|---|
    | 目的 | 学习规律 | 生成回答 |
    | 是否更新模型参数 | 会 | 通常不会 |
    | 成本 | 极高 | 相对较低 |
    | 发生场景 | 模型厂商训练模型 | 用户调用模型 |
    | 类比 | 学生长期学习 | 考试时作答 |
3. Token是什么？
    
    token是模型处理文本的基本单位。
    它不一定等于一个字或等于一个词。
    
    具体取决于tokenizer

    模型看不懂原始文字，它看到的是 token 编号。

    完整流程：

    ```
    用户输入文本
    -> tokenizer 把文本切成token
    -> token 转成数字ID
    -> 模型处理这些数字
    -> 模型预测下一个token ID
    -> tokenizer把 ID 解码回文字
    ```
4. 为什么模型是在预测下一个token

    大模型生成回答时，本质是一个一个token往外吐。

    每一步，根据前面的上下文，计算下一个token的概率分布。

    ```
    中国的首都是
    ```
    | 下一个 token | 概率 |
    |---|---|
    | 北京 | 95% |
    | 上海 | 2% |
    | 南京 | 1% |
    | 其他 | 2% |

    然后选择一个token输出。
