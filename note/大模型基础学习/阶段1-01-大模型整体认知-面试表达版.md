# 阶段1-01-大模型整体认知：面试表达版

## 1. 什么是大语言模型？

大语言模型可以理解为一个通过海量文本数据训练出来的神经网络。

它的核心能力是：根据已有上下文，预测接下来最可能出现的内容。它不是传统意义上的数据库，也不是简单地从资料里查答案，而是通过训练学习到了语言规律、知识关联、代码模式和一定的推理模式。

比如输入：

```text
中国的首都是
```

模型会根据训练中学到的大量语言模式，判断后面最可能出现的是：

```text
北京
```

所以，大语言模型本质上是一个概率生成模型，它根据上下文逐步生成文本。

## 2. 训练和推理有什么区别？

训练和推理是大模型的两个不同阶段。

训练阶段是模型学习规律的过程。它会阅读海量文本，不断练习一个核心任务：

```text
给定前面的 token，预测下一个 token
```

如果模型预测错了，就会根据误差调整内部参数。这个过程需要大量数据、GPU 算力和训练时间。

推理阶段是使用已经训练好的模型来生成回答。当用户向模型提问时，模型通常不会再更新参数，而是根据当前输入一步步预测并生成输出。

可以这样对比：

| 维度 | 训练 | 推理 |
|---|---|---|
| 目的 | 学习语言和知识规律 | 根据输入生成回答 |
| 是否更新参数 | 会更新 | 通常不会更新 |
| 成本 | 很高，需要大量算力 | 相对较低 |
| 发生场景 | 模型厂商训练模型 | 用户调用模型或 API |
| 类比 | 学生长期学习 | 考试时现场作答 |

一句话总结：训练是让模型学会规律，推理是让模型使用这些规律生成答案。

## 3. Token 是什么？

Token 是模型处理文本的基本单位。

它不一定等于一个汉字，也不一定等于一个完整单词，具体怎么切分取决于 tokenizer。

模型不能直接理解原始文字。用户输入的文本会先经过 tokenizer，被切分成 token，然后每个 token 会被转换成数字 ID。模型实际处理的是这些数字 ID，而不是直接处理中文、英文或代码字符。

完整流程可以概括为：

```text
用户输入文本
-> tokenizer 将文本切分成 token
-> token 转换成数字 ID
-> 模型处理这些数字 ID
-> 模型预测下一个 token ID
-> tokenizer 将 token ID 解码成人类可读的文本
```

所以在大模型里，token 是连接自然语言和模型计算的桥梁。

## 4. 为什么说模型是在预测下一个 token，而不是在查答案？

大模型生成回答时，并不是一次性生成完整答案，而是一个 token 一个 token 地往外生成。

每一步，模型都会根据已有上下文计算下一个 token 的概率分布，然后选择一个 token 输出。

例如输入：

```text
中国的首都是
```

模型可能会计算出类似这样的概率：

| 下一个 token | 概率 |
|---|---|
| 北京 | 95% |
| 上海 | 2% |
| 南京 | 1% |
| 其他 | 2% |

如果“北京”的概率最高，模型就可能输出“北京”。随后，它会把已经生成的内容加入上下文，继续预测下一个 token，直到生成完整回答或遇到停止条件。

因此，大模型并不是像搜索引擎一样去数据库中查找固定答案，而是根据上下文和参数，动态生成最可能的文本序列。

## 5. 一分钟面试回答

大语言模型本质上是一个通过海量文本训练出来的概率生成模型。它的核心训练目标通常是根据前面的 token 预测下一个 token。训练阶段会使用大量数据和算力来调整模型参数，让模型学习语言规律、知识关联和代码模式；推理阶段则是使用已经训练好的参数，根据用户输入一步步生成回答，通常不会更新模型参数。

模型并不是直接处理原始文字，而是先通过 tokenizer 把文本切分成 token，再转换成数字 ID。模型根据上下文预测下一个 token ID，最后再由 tokenizer 解码成人类可读的文本。

所以说，大模型不是简单地查答案，而是在当前上下文下不断预测下一个最可能的 token，并把这些 token 串起来形成最终回答。

## 6. 面试官可能追问

### Q1：大模型为什么会出现幻觉？

因为模型本质上是在根据上下文生成概率上最可能的文本，而不是在保证事实一定正确。当上下文信息不足、训练数据中存在错误，或者模型对问题不确定时，它仍然可能生成一个看起来合理但实际上错误的答案。

### Q2：推理阶段会不会学习用户的新知识？

通常不会。推理阶段一般不会更新模型参数。模型可以在当前上下文窗口内利用用户提供的信息，但这更像是临时上下文，并不等于模型真正学会了新知识。除非进行微调、继续训练，或者把信息写入外部记忆系统。

### Q3：Token 为什么会影响成本和上下文长度？

因为模型的输入和输出都是按 token 计算的。上下文窗口限制的是 token 数量，不是字数；API 计费通常也和输入、输出 token 数量有关。所以同样一段内容，不同语言、不同格式、不同 tokenizer 下的 token 数可能不同。
