第 1-3 天：大模型整体认知

学习内容：LLM 是什么、训练和推理区别、Token、上下文窗口、为什么模型会“续写”。

产出：一篇笔记《大模型请求到回答的完整流程》。

第 4-7 天：Transformer 和 Attention

学习内容：Transformer 架构、Self-Attention、多头注意力、位置编码、Decoder-only。
重点不要钻数学细节，先理解“每个 token 如何看其他 token”。

产出：手画一张 Transformer 推理流程图，能口述 3 分钟。

第 8-10 天：Tokenization

学习内容：BPE/WordPiece 直觉、中英文 token 差异、特殊 token、上下文长度限制。

实践：用 tokenizer 工具测试中文、英文、代码、长文本的 token 数。

产出：记录 5 组输入的 token 对比。

第 11-14 天：推理参数实验

学习内容：temperature、top_p、top_k、frequency penalty、presence penalty、max_tokens、stop。

实践：同一个问题改不同参数，对比输出稳定性、创造性、长度、重复程度。

产出：一张参数实验表。

第 15-18 天：Python API 调用

学习内容：API Key、环境变量、请求/响应结构、多轮 messages、流式输出、异常处理。

实践：写一个命令行聊天脚本，支持多轮对话和流式输出。

产出：一个可运行 demo。

第 19-21 天：复盘与模拟面试

学习内容：整理第一阶段知识地图。

练习：回答 15-20 道大模型基础题。

产出：阶段总结文档 + 自测清单。
